# HSCA Recipe Database

A comprehensive, production-ready recipe database application featuring 457+ high-quality recipes from the HSCA culinary arts program.

## 📁 Project Structure

```
HSCA Recipe Database/
├── src/                    # Main application source code
│   ├── components/         # React components
│   ├── data/
│   │   └── recipes/        # Recipe database (457+ recipes)
│   ├── pages/              # Next.js pages
│   ├── types/              # TypeScript type definitions
│   └── utils/              # Utility functions
├── docs/                   # Documentation
├── scripts/                # Maintenance and utility scripts
├── tools/                  # Processing tools
├── reports/                # Final validation and analysis reports
├── enhanced_extracted_recipes/  # Final processed recipe data
├── public/                 # Static assets
├── cleanup_backup/         # Backup of critical files before cleanup
├── package.json            # Dependencies and scripts
├── yarn.lock               # Lockfile
└── tsconfig.json           # TypeScript configuration
```
