# HSCA Recipe Extraction Documentation

## Overview

This directory contains documentation for the HSCA Recipe Extraction project, a comprehensive system for digitizing and extracting recipes from culinary school materials.

## Files

- **`RECIPE_EXTRACTOR_DEVELOPMENT_PHASES.md`** - Complete development history and phases of the extraction system
- **`claude.md`** - Project overview and quick start guide
- **`examples/`** - Sample recipe files and examples
  - `Deep_Fried_Chicken_Marsala_Recipe.md` - Example of a processed recipe

## Related Documentation

- **`../reports/`** - Analysis reports and accuracy assessments
- **`../output/`** - Processed recipe databases and outputs
